# 신미례 | Frontend Developer

사용자의 흐름과 상태 변화를 구조적으로 설계하는 4년 차 프론트엔드 개발자입니다.

React와 TypeScript를 중심으로 웹과 Electron 데스크톱 환경을 다룹니다. 서버 상태·클라이언트 상태·URL 상태의 경계를 명확히 나누고, 기능이 확장되어도 변경 범위가 예측 가능한 구조를 만드는 데 관심이 있습니다. Electron에서는 IPC 설계부터 패키징과 자동 업데이트까지 제품 배포 흐름을 경험했습니다. 필요한 백엔드 API와 배포·검증 환경까지 직접 연결하며 제품의 전체 흐름을 이해하려고 합니다.

## What I value

- 복잡한 사용자 흐름을 컴포넌트와 도메인 경계로 나눕니다.
- 로딩·오류·빈 상태까지 포함해 예측 가능한 UI를 설계합니다.
- 측정을 바탕으로 렌더링과 사용자 흐름의 병목을 찾고, 개선 결과를 모니터링합니다.
- 선택한 구조와 문제 해결 과정을 다른 개발자가 이해할 수 있게 기록합니다.
- CI와 배포를 연결해 언제든 검증 가능한 상태로 유지합니다.
